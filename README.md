역사 입문자도 부담 없이 핵심 사건·인물부터 시대 흐름까지 익힐 수 있도록 만든 **단일 파일 기반 웹 퀴즈 게임**입니다. 한국사(조선전기·조선후기)와 세계사(유럽사)를 아우르며, 가벼운 게임 요소와 친절한 오답 해설을 결합했습니다.

---

## 주요 기능

### 1. 학습 영역 및 난이도
| 구분 | 제공 옵션 | 설명 |
| :--- | :--- | :--- |
| **학습 영역** | 전체 혼합 / 조선전기 / 조선후기 / 유럽사 | 원하는 시대만 골라 집중 학습하거나 전체 혼합 모드로 풀 수 있습니다. |
| **난이도** | 단계별 자동 상승(추천) / Lv.1 왕초보 / Lv.2 도약 / Lv.3 연표 마스터 | 자동 상승 모드에서는 초보 문제로 시작해 점차 시대 흐름·연표 문제로 이어집니다. |
| **문제 수** | 5문제 / 7문제 / 전체 풀기 | 학습 시간에 맞춰 라운드 길이를 조절할 수 있습니다. |

### 2. 문제 유형
- **4지선다 객관식**: 핵심 인물, 사건, 제도를 4개의 보기 중 선택합니다. 키보드 숫자 키(`1`~`4`)로도 빠르게 답을 고를 수 있습니다.
- **연표 맞추기**: 섞여 있는 4개의 사건 카드를 가장 오래된 사건부터 최근 사건 순서대로 슬롯에 클릭해 배치합니다.

### 3. 왕초보를 위한 학습 지원
- **선택한 오답 상세 분석**: 틀린 보기를 골랐을 때 단순히 정답만 알려주지 않고, **내가 고른 보기가 실제로 어떤 인물·사건인지**까지 별도로 짚어줍니다. 연표 문제의 경우 내가 배치한 순서의 실제 연도와 올바른 연표를 나란히 비교해 보여줍니다.
- **힌트 보기**: 문제당 1회 힌트를 열어 핵심 키워드를 확인할 수 있습니다. (힌트 사용 시 기본 점수에서 25점 차감, 최소 50점 보장)
- **핵심 연표 미리보기**: 상단 `📜 핵심 연표` 버튼을 누르면 조선전기·조선후기·유럽사의 주요 연표를 한눈에 훑어볼 수 있습니다.
- **틀린 문제 다시 풀기**: 오답은 자동으로 저장되며, 홈 화면이나 결과 화면의 `틀린 문제 다시 풀기` 버튼으로 복습할 수 있습니다. 복습에서 맞히면 오답 목록에서 자동 해제됩니다.

### 4. 가벼운 게임 요소
- **레벨 및 경험치(XP) 시스템**: 문제를 맞힐 때마다 경험치가 쌓여 `Lv.1 역사 새싹`부터 `Lv.5 타임점프 마스터`까지 성장합니다.
- **콤보 & 3단 폭죽 이펙트**: 연속 정답 시 콤보 보너스 점수가 추가되며, 정답을 맞힐 때마다 `canvas-confetti` 기반의 3단 폭죽과 한국사·세계사 주제에 맞춘 랜덤 축하 멘트가 출력됩니다.
- **효과음 토글**: Web Audio API로 합성한 정답·오답·클릭·레벨업 효과음을 상단 `🔊 효과음` 버튼으로 켜고 끌 수 있습니다.

---

## 기술 스택 및 저장 방식
- **구성**: 별도 서버나 빌드 과정이 필요 없는 단일 HTML 파일 (`history_quiz.html`)
- **스타일 & 이펙트**: Tailwind CSS (`3.4.17` CDN), `canvas-confetti` (`1.9.3` CDN), Web Audio API
- **데이터 저장**: 브라우저 `localStorage`(`timejump_history_quiz_v1` 키)에 누적 XP, 최고 콤보, 정답률, 오답 목록을 저장합니다.

---

## 실행 방법
1. `history_quiz.html` 파일을 Chrome, Safari, Edge 등 최신 웹 브라우저에서 엽니다.
2. 홈 화면에서 **시대(영역)**, **난이도**, **문제 수**를 고른 뒤 `🚀 퀴즈 시작하기`를 누릅니다.
3. 풀이 중 `1`~`4` 키로 보기를 선택하고, 해설 확인 후 `Enter` 키로 다음 문제로 바로 넘어갈 수 있습니다.
